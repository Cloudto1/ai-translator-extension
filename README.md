# AI 翻译助手（Microsoft Edge / Chrome 扩展）

基于大模型的浏览器翻译插件，提供 **全页面翻译**、**划词翻译**、**网页总结** 三大能力，并配备独立的 **管理面板** 用于配置、查看翻译历史与 Token 消耗统计。
兼容 OpenAI Chat Completions 协议，API Key、Base URL、模型名全部由用户自行配置，数据只在你与所选服务商之间流转。

## 功能

| 功能 | 说明 |
| --- | --- |
| 全页面翻译 | 自动识别页面正文，分批调用模型翻译；支持「替换原文」与「双语对照」两种模式，再次点击即可一键恢复原文 |
| 划词翻译 | 选中文字后出现悬浮按钮，点击即得到译文；也可开启「划词后自动翻译」直接出结果，译文支持流式输出与一键复制 |
| 网页总结 | 抽取页面正文，生成「一句话总结 + 要点列表」，流式展示在右侧抽屉中 |
| 语言设置 | 源语言支持自动识别或指定；目标语言支持自动（中 ⇄ 英 互译）或指定 9 种语言，可一键交换方向 |
| 翻译记录 | 自动记录每次整页翻译 / 划词翻译 / 网页总结，支持按类型筛选、关键词搜索、复制结果、打开来源与删除 |
| Token 统计 | 统计调用次数、总 Token（输入 / 输出）、翻译字符数与平均耗时，含近 7/14/30 天趋势图、按功能与按模型分布 |
| 快捷入口 | 扩展弹窗、右键菜单、快捷键（`Alt+Shift+T` 整页 / `Alt+Shift+S` 总结 / `Alt+Shift+E` 划词）三处入口 |

## 安装（Edge）

1. 打开 `edge://extensions/`，开启左下角的 **开发人员模式**。
2. 点击 **加载解压缩的扩展**，选择本项目根目录（含 `manifest.json` 的目录）。
3. 点击工具栏中的扩展图标，在弹出的 **设置** 页填写：
   - **API Key**：如 `sk-xxxxxxxx`
   - **Base URL**：如 `https://api.deepseek.com`（可填 OpenAI、DeepSeek、各类网关地址）
   - **模型**：如 `deepseek-flash`、`gpt-4o-mini` 等
4. 点击 **测试连接**，看到「连接成功 · xxx ms」即可使用。

> Base URL 会自动补全为 `.../v1/chat/completions`；直接粘贴完整端点也能正确识别。
>
> 出于安全考虑，公网地址必须使用 `https://`：API Key 放在请求头里，明文 `http://` 会被沿途的网络设备窃听。只有本机和局域网地址（如 `http://localhost:11434`、`http://192.168.x.x`）允许使用 `http://`。

## 使用

- **翻译整页**：点扩展图标 → 翻译整个页面；或右键页面 → 「AI 翻译：翻译整个页面」；或 `Alt+Shift+T`。再执行一次即恢复原文。
- **划词翻译**：在页面上选中任意文字 → 点击悬浮的「译 划词翻译」按钮（或在快捷操作中开启自动翻译）。
- **总结网页**：点扩展图标 → 总结当前网页；或右键页面 → 「AI 翻译：总结此页面」；或 `Alt+Shift+S`。按 `Esc` 关闭面板。

## 管理面板

打开方式（任选其一）：

- 点击扩展弹窗底部的 **打开管理面板**
- `edge://extensions/` → 找到本扩展 → **详细信息** → **扩展选项**
- 右键扩展图标 → **选项**

面板包含四个页面：

| 页面 | 内容 |
| --- | --- |
| **概览与统计** | 4 张指标卡（调用次数 / 总 Token / 翻译字符 / 平均耗时）+ 近 7/14/30 天 Token 趋势柱状图 + 按功能分布 + 按模型分布 |
| **翻译记录** | 每次翻译的原文与结果对照、语言对、时间、Token、耗时、模型；支持按类型筛选、关键词搜索、复制结果、打开来源页面、删除单条或清空全部 |
| **语言设置** | 源语言与目标语言（含一键交换与常用语言组合），页面翻译方式、总结详细程度、历史上限、划词自动翻译、关闭模型思考 |
| **API 设置** | API Key（可显示/隐藏）、Base URL、模型、测试连接、恢复默认设置，以及快捷键说明 |

### 设置项说明

| 设置 | 作用 |
| --- | --- |
| 源语言 | `自动识别` 时由模型判断原文语言；指定后可提升特定语言对的准确率。若与目标语言相同会自动反向翻译 |
| 目标语言 | `自动` = 中 ⇄ 英 互译；也可固定为某一语言。总结在「自动」时输出中文 |
| 划词后自动翻译 | 选中即翻译，省去点击按钮 |
| 页面翻译方式 | 「替换原文」或「双语对照（原文 + 译文）」 |
| 总结详细程度 | 简短 / 标准 / 详细 |
| 历史记录保留条数 | 本地最多保留多少条翻译记录，默认 300 条 |
| 关闭模型思考过程 | 对推理类模型发送 `thinking: {"type":"disabled"}`，显著提速降本；若服务商不支持该参数，插件会自动去掉并重试 |

## 项目结构

```
manifest.json                     MV3 清单
src/
  lib/
    config.js                     默认设置、Base URL 规范化、校验
    api.js                        OpenAI 协议客户端（含 SSE 流式解析、用量归一化、错误友好化）
    prompts.js                    提示词构造、源/目标语言对解析
    translate.js                  批量翻译：分批、并发、解析、漏译重试、用量聚合
    summarize.js                  正文清洗与总结
    history.js                    翻译记录与 Token 统计（纯函数）
    protocol.js                   消息/端口协议常量
    access.js                     后台消息的调用方鉴权（特权操作只认扩展页面）
    cache.js                      按站点隔离的翻译缓存（LRU，含条数与体积上限）
    storage.js                    chrome.storage 读写（设置 + 历史 + 缓存，写入串行化）
  background/service-worker.js    集中发起 AI 请求、右键菜单、快捷键、端口路由、写历史
  content/content.js              页面内 UI（Shadow DOM）、三种功能实现
  popup/                          配置与快捷操作弹窗
  options/                        管理面板（统计 / 记录 / 语言 / API）
icons/                            图标
tests/
  unit.test.mjs                   离线单元测试
  robustness.test.mjs             离线回归测试（鉴权 / API 容错 / 失败处理，全部桩 fetch）
  integration.test.mjs            真实 API 集成测试
  e2e.run.mjs                     Edge 端到端测试（真实加载扩展）
```

设计要点：

- 所有 AI 请求都在 **Service Worker** 中发起，绕开页面 CORS 限制，且 API Key 不会被页面脚本读取。
- 页面内 UI 全部渲染在 **Shadow DOM** 中，与宿主页面样式完全隔离。
- 全页面翻译按「条目数 + 字符数」双阈值分批，3 路并发；模型返回格式异常时自动拆批重试，若整句被当作专有名词原样返回则会强引导重试补译。
- API 客户端会自动处理第三方网关的差异：不认识的参数（`thinking` / `temperature` / `stream_options` / `max_tokens`，以及只认 `max_completion_tokens` 的模型）逐个降级重试；遇到 429 / 502 / 503 / 504 按 `Retry-After` 退避重试最多 2 次；批量翻译中任一批失败会立即中止其余在途请求，不再白烧 Token。
- Token 用量取自接口返回的 `usage`，整页翻译会把多批请求的用量累加；流式请求通过 `stream_options.include_usage` 获取用量，网关不支持时自动降级。
- 历史记录写入 `chrome.storage.local` 并串行化，避免并发批次互相覆盖；管理面板通过 `chrome.storage.onChanged` 实时刷新，无需手动刷新页面。

## 开发与测试

```bash
npm install          # 安装测试依赖（playwright）
npm test             # 单元测试 + 真实 API 集成测试
npm run test:unit    # 仅离线单元测试
npm run test:e2e     # 在真实 Edge 中加载扩展跑端到端测试
```

测试规模：**68 项离线测试 + 18 项真实 API 集成测试 + 40 项 Edge 端到端测试**。

测试使用的 API 配置可通过环境变量覆盖：`AIT_API_KEY`、`AIT_BASE_URL`、`AIT_MODEL`。
E2E 测试会自动启动本地站点、在真实 Edge 中加载扩展，覆盖 popup 配置、整页翻译与恢复原文、双语对照、划词翻译（中英双向）、自动划词、网页总结、未配置提示、popup → 后台 → 内容脚本全链路，以及管理面板的统计渲染、语言切换、连接测试、历史记录实时更新、筛选搜索删除与面板入口，截图输出到 `tests/.artifacts/`。

## 兼容性

- 浏览器：Edge / Chrome 110+（Manifest V3）。
- 模型：任何兼容 OpenAI `chat/completions` 的服务，包括 DeepSeek、OpenAI、通义、Moonshot 以及自建网关。
- 使用 DeepSeek 时注意：模型列表里的显示名 `DeepSeek-V4.1-Flash` 对应的 API 模型 ID 是 **`deepseek-flash`**，请填写 ID。
- 翻译与总结均为纯文本调用，不依赖工具调用 / 多模态能力。

## 隐私

- 仅在你主动触发翻译或总结时，才会把对应文本发送到你配置的模型服务商。
- 插件自身不收集、不上报任何数据。API Key 存放在 `chrome.storage.sync`，翻译历史与 Token 统计存放在 `chrome.storage.local`，均只保存在本机浏览器中。
- 注入网页的内容脚本拿不到 API Key：后台返回给它的设置里 Key 是空的，改配置、测连接、清缓存等特权操作也只接受来自扩展自己页面（弹窗 / 管理面板）的请求。
- Base URL 校验拒绝「公网地址 + 明文 http」，避免 API Key 在网络上裸奔。
- 历史记录里的来源链接只放行 `http(s)`，不会渲染 `javascript:` / `data:` 链接。
- 历史记录中的原文与结果最多各保留 500 字符预览（超出以省略号截断），可在管理面板中随时删除单条或清空全部。
