它是什么

What it is

AI 翻译助手是一个浏览器扩展。它不替你决定用哪个模型——API Key、Base URL、模型名全部由你填写，可以接 DeepSeek、OpenAI、通义、Moonshot，也可以接你自己的网关。

  • 请求在后台发出

    所有 AI 请求由 Service Worker 统一发起，绕开页面的跨域限制，API Key 不会暴露给任何网页脚本。

  • 页面内的界面是隔离的

    翻译按钮、译文卡片、总结抽屉都渲染在 Shadow DOM 里，既不被网页样式影响，也不打扰网页本身。

  • 不收集，不上报

    只有你主动触发翻译或总结时，才会把对应的文字发往你自己配置的服务商。插件本身不采集任何数据。

安装

Install

Edge / Chrome 110+，Manifest V3

  1. 打开扩展管理页

    在地址栏输入 edge://extensions/（Chrome 则是 chrome://extensions/），打开左下角的「开发人员模式」。

  2. 加载解压缩的扩展

    点击「加载解压缩的扩展」，选择包含 manifest.json 的项目根目录。

  3. 填写模型配置

    点击工具栏中的扩展图标，在弹出的设置页填写三项信息。Base URL 会自动补全为 …/v1/chat/completions，直接粘贴完整端点也能识别。

    API Keysk-xxxxxxxx Base URLhttps://api.deepseek.com 模型deepseek-flash

  4. 测试连接

    点击「测试连接」，看到「连接成功 · xxx ms」就可以开始用了。
