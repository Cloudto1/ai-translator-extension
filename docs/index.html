安装

四步装好，不用注册

支持 Microsoft Edge 与 Google Chrome 110 及以上版本。

  1. 下载并解压

    下载 ZIP 解压到任意目录，确认里面有 manifest.json。会用 git 的话也可以直接克隆：

    git clone https://github.com/Cloudto1/ai-translator-extension.git

    没装 git 也没关系，下载 ZIP 效果一样。

  2. 打开开发者模式

    地址栏输入 edge://extensions 或 chrome://extensions，打开「开发人员模式」开关。

  3. 加载扩展

    点「加载解压缩的扩展」，选中含 manifest.json 的那个文件夹。

  4. 填好模型配置

    点工具栏里的图标进入设置，填 API Key、Base URL 和模型名，点「测试连接」看到成功即可开用。

常见问题

装之前你可能想知道

要花钱吗？

插件本身免费开源。翻译调用的是你自己的模型服务，按服务商的价格计费；有翻译缓存，同样的句子不会重复扣 Token。

我的网页内容会被上传吗？

插件没有自己的服务器。只有你按下翻译或总结时，对应的文字才会直接发给你在设置里填写的那个服务商。

为什么不在应用商店上架？

目前以开源方式发布，通过「加载解压缩的扩展」安装，代码完全可见。更新时重新下载并在扩展页点「重新加载」即可。

翻译乱了页面怎么办？

再按一次 AltShiftT 或在弹窗里再点一次「翻译整个页面」，页面立即还原，不需要刷新。
