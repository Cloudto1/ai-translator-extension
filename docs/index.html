产品介绍

它是什么

What it is

AI 翻译助手是一个浏览器扩展。它不替你决定用哪个模型——API Key、Base URL、模型名全部由你填写，可以接 DeepSeek、OpenAI、通义、Moonshot，也可以接你自己的网关。

  • 请求在后台发出

    所有 AI 请求由 Service Worker 统一发起，绕开页面的跨域限制，API Key 不会暴露给任何网页脚本。

  • 页面内的界面是隔离的

    翻译按钮、译文卡片、总结抽屉都渲染在 Shadow DOM 里，既不被网页样式影响，也不打扰网页本身。

  • 不收集，不上报

    只有你主动触发翻译或总结时，才会把对应的文字发往你自己配置的服务商。插件本身不采集任何数据。

Three ways to read

全页面翻译

自动识别页面正文，分批调用模型翻译，长文也能边翻边读。可以「替换原文」，也可以「双语对照」——原文与译文逐段并排，再点一次即一键恢复原文。

安装指南

四步装好，不用注册

Install

下载解压、加载到浏览器、填一次 API 配置即可。Edge 与 Chrome 110 及以上版本都支持。

  1. 下载扩展文件

    从 GitHub 下载 ZIP 并解压到本地任意目录。解压后确认根目录下能看到 manifest.json——它就是第三步要选的文件夹。

    下载 ZIP 在 GitHub 查看

    git clone https://github.com/Cloudto1/ai-translator-extension.git

  2. 打开开发者模式

    在地址栏输入 edge://extensions/（Chrome 则是 chrome://extensions/），打开页面左下角的「开发人员模式」。

  3. 加载扩展程序

    点击「加载解压缩的扩展」，选择刚才解压出来、包含 manifest.json 的文件夹。

  4. 填写配置并测试连接

    点击工具栏中的扩展图标，在设置页填写三项信息，再点「测试连接」。看到「连接成功」就可以开始用了。
